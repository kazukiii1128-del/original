# GROSMIMIインスタモニター募集 管理ワークフロー

## 目的

インスタグラムのモニター募集に応募したフォーム回答者の情報を一元管理し、希望カラーをシートに自動反映する。

---

## 管理対象

| 項目 | 内容 |
|------|------|
| Googleフォーム | フォーム回答者の応募情報を収集 |
| Googleシート | 回答データの一覧管理（フォームと連携） |
| インスタ投稿 | コメントで希望カラーを収集（https://www.instagram.com/p/DWBMJ3-Eenj/） |
| Apps Script | 毎日希望カラーを自動更新 |

**Googleシート URL:**
`https://docs.google.com/spreadsheets/d/10byx-K5Xv8uOgp7o2Qd7b3ZaOwYkZx2RwUB6xMj1Bzc/`

---

## 自動化済みの処理

### 希望カラー自動更新（毎日09:00 JST）

Apps Scriptプロジェクト：
`https://script.google.com/u/0/home/projects/1PyH_Ka3-RMyg6Xir17eibFGnYpdmacA5lOq82KM9hZVD3vZ8UoeFFEGu/edit`

- 関数名：`addColorColumn`
- トリガー：時間ベース・日単位・午前9時〜10時
- 動作：インスタコメントから収集した希望カラーを、フォーム回答者のみ「希望カラー」列（L列）に記入
- **フォーム未提出者は記入しない**（インスタコメントのみの人は対象外）
