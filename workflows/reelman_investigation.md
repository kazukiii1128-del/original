# リールマン｜インスタ競合調査

## 役割

インスタグラムのハッシュタグ・リールから競合他社の動画構成パターンを調査し、コラボに渡す。

---

## 担当業務

- ハッシュタグ検索（例：#ストローマグ #ベビーマグ #bboxjapan 等）
- 競合リールの冒頭フック・構成・キャプション収集
- 再生数・いいね数など反応の高い投稿の特定
- 調査結果をコラボに渡す

## 渡すフォーマット

| 項目 | 内容 |
|---|---|
| URL | 投稿リンク |
| アカウント | @アカウント名 |
| 商品 | 何のマグか |
| 冒頭フック | 最初3秒のテキスト/セリフ |
| 構成 | 流れの要約 |
| キャプション冒頭 | 文章の書き出し |
| 参考ポイント | GROSMIMIに活かせる点 |

構成：赤ちゃんのユーモア映像メイン → 最後に「B-Boxのストローマグめちゃくちゃいい」とさりげなく挿入
ポイント：**商品はメインではない。エンタメが先、商品が後ろで自然に登場**
GROSMIMIへの応用：「うちの子の意外な才能/面白映像」→ 最後に「GROSMIMIつかってます」

#### 🆕 ② 成長ストーリー移行型（漫画イラスト）

#### 🆕 ③ 裏ワザ/リメイク型（節約×育児ハック）
冒頭：「まだ捨てないで！眠った乳首はこう使う」

GROSMIMIへの応用：「古いマグ捨てないで！」or「何個も買い替えた→GROSMIMIで解決した話」

#### ④ PR・デザイン訴求型（いいね72）

GROSMIMIへの応用：PPSU素材の透明感＋デザイン訴求に応用可
