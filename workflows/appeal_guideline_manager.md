# ガイドラインマン｜カテゴリー別訴求ガイドライン管理

## 役割

「ガイドラインマン」と呼ばれたら起動する。

GROSMIMIのインフルエンサーコラボ動画において、カテゴリー別に「何を・どう伝えるか」のルールを作成・管理・更新する。
コラボが設計した構成パターンをもとに、インフルエンサーが実際に使えるレベルまで落とし込む。

---

## 担当業務

- カテゴリーごとの訴求ルール（言っていいこと・ダメなこと・必須ワード）を整備
- ガイドラインをインフルエンサーへのブリーフィング資料として使える形に仕上げる
- コラボから新カテゴリーが追加されたらガイドラインを追加する
- リールマンの調査結果をもとにガイドラインを随時アップデートする

## カテゴリー別訴求ガイドライン（現行版）

---

### 【PPSUグループ】

#### ① PPSU素材・安全性

**訴求の核心**
> 「素材に種類があることを知らない親が多い」という知識格差を使う

| 項目 | ルール |
|---|---|
| 必須ワード | PPSU・BPAフリー・マイクロプラスチックなし・医療グレード |
| 推奨フック | 「安いプラスチックで十分、ちょっと待って」「プラスチックに種類があること知ってた？」|
| 言っていいこと | PPSU素材の安全性・耐熱性・BPAフリーであること |
| 言ってはいけないこと | 他社商品を名指しで「危険」と断言すること |
| 感情の着地点 | 「毎日使うものだから素材を妥協したくない」 |
| 推奨パターン | 逆張り教育型 |

---

#### ② 漏れない（PPSUグループ）

**訴求の核心**
> カバンの中で漏れたあるある体験から入り、+CUTストローの仕組みで解決する

| 項目 | ルール |
|---|---|
| 必須ワード | +CUTストロー・逆さにしても漏れない・振っても大丈夫 |
| 推奨フック | 「カバンの中でマグが漏れてたことある人〜？」 |
| 言っていいこと | 逆止弁の仕組み・逆さ/振る/落とす実証 |
| 言ってはいけないこと | 「絶対漏れない」と断言（使用状況による） |
| 感情の着地点 | 「外出中の不安がゼロになった」 |
| 推奨パターン | ペイン共感型 |
| 強みポイント | 実証動画のインパクトを最大化。逆さに振るシーンは必須 |

---

#### ③ 離乳食期に使える

**訴求の核心**
> 離乳食スタート＝マグデビューのタイミングとして一緒に買うべきアイテムとして訴求

| 項目 | ルール |
|---|---|
| 必須ワード | 離乳食デビューに・6ヶ月から・BPAフリー・神グッズ |
| 推奨フック | 「離乳食始めたなら絶対これも一緒に揃えて」 |
| 言っていいこと | 6ヶ月対応・安全素材・離乳食グッズとのセット提案 |
| 言ってはいけないこと | 月齢の断言（「必ず6ヶ月から使える」等。個人差があるため） |
| 感情の着地点 | 「離乳食と一緒に揃えておけば良かった」 |
| 推奨パターン | ランキング・まとめ型 |
| タグ戦略 | #離乳食タグに乗せることで新規層リーチ |

---

#### ④ ストロー練習

**訴求の核心**
> 赤ちゃんが自然と飲めるようになるまでのリアルなチャレンジ動画

| 項目 | ルール |
|---|---|
| 必須ワード | ストロー練習・一発で飲めた・自然と覚えた |
| 推奨フック | 「何回やっても飲めなかったのに、これにしたら一発で飲めた」 |
| 言っていいこと | 練習成功の過程・飲みやすい設計であること |
| 言ってはいけないこと | 「必ず飲めるようになる」等の保証表現 |
| 感情の着地点 | 「ストロー練習中のママへ」として共感で締める |
| 推奨パターン | 比較体験談型 |
| 動画素材 | 赤ちゃんのリアルな練習シーン（失敗→成功）が最も効果的 |

---

#### ⑤ 保冷・衛生（夏向け）

**訴求の核心**
> 夏の外出・熱中症対策・麦茶の鮮度問題として衛生訴求

| 項目 | ルール |
|---|---|
| 必須ワード | 保冷・夏の外出・麦茶・衛生・雑菌 |
| 推奨フック | 「夏に赤ちゃんに持たせるマグ、中身大丈夫？」 |
| 言っていいこと | PPSU素材のにおい移りしにくさ・洗いやすさ・安全素材 |
| 言ってはいけないこと | 保温効果（PPSUに保温機能はない。ステンレスの訴求） |
| 感情の着地点 | 「夏こそ素材にこだわりたい」 |
| 推奨パターン | ペイン共感型 |

---

#### ⑥ ストロー構造メイン

**訴求の核心**
> ストローそのものの設計（長さ・素材・逆止弁）が他社と違うことを教育する

| 項目 | ルール |
|---|---|
| 必須ワード | +CUTストロー・逆止弁・シリコンストロー |
| 推奨フック | 「ストローマグのストロー、交換してる？」 |
| 言っていいこと | ストローの素材・構造・洗いやすさ・替えストローの存在 |
| 言ってはいけないこと | 具体的な競合商品名を出して比較 |
| 感情の着地点 | 「ストローこそこだわるべきだった」 |
| 推奨パターン | 逆張り教育型 |

### 【ステンレスグループ】

#### ① 医療グレード・保温保冷

**訴求の核心**
> ステンレスに種類があることを知らない人への知識教育

| 項目 | ルール |
|---|---|
| 必須ワード | SUS316・医療グレード・保温6時間・変色しない |
| 推奨フック | 「ステンレスマグなら全部同じだと思ってた」 |
| 言っていいこと | SUS316の安全性・保温実証・韓国ブランドの権威性 |
| 言ってはいけないこと | SUS201・304を「危険」と断言。「医療器具と同じ素材」は可、「医療器具」とは言わない |
| 感情の着地点 | 「知ってたらこっちを選んでた」 |
| 推奨パターン | 逆張り教育型 |

---

#### ② 漏れない（保温×漏れない両立）

**訴求の核心**
> 「保温できて漏れないマグ」という両立が従来なかったことを伝える

| 項目 | ルール |
|---|---|
| 必須ワード | 保温6時間・HOT対応・倒してもこぼれない・真空断熱 |
| 推奨フック | 「ホットを入れて倒しても漏れないマグ、存在してた」 |
| 言っていいこと | 保温実証・漏れない実証（逆さ・落とす）・外出シーン |
| 言ってはいけないこと | 「熱湯をそのまま入れても安全」等の過度な安全宣言 |
| 感情の着地点 | 「外出に最強の組み合わせ」 |
| 推奨パターン | ペイン共感型 |

---

#### ③ シームレス・衛生

**訴求の核心**
> 「継ぎ目＝カビ・汚れ」ペインに直撃。シームレス構造で解決

| 項目 | ルール |
|---|---|
| 必須ワード | シームレス構造・継ぎ目なし・カビない・内側まで清潔 |
| 推奨フック | 「ステンレスマグ、内側に継ぎ目があるやつ使ってない？」 |
| 言っていいこと | 溶接ありとシームレスの構造比較・洗いやすさ |
| 言ってはいけないこと | 「他社は全部カビる」等の過度な競合批判 |
| 感情の着地点 | 「衛生面の不安が完全になくなった」 |
| 推奨パターン | 逆張り教育型 |

---

#### ④ 比較・買い替え訴求

**訴求の核心**
> 「前のマグに戻れない」感情で買い替え需要を喚起

| 項目 | ルール |
|---|---|
| 必須ワード | 後悔した・これに変えて正解・第二子はこれ一択 |
| 推奨フック | 「今まで使ってたマグ、正直ゴミだったと気づいた話」 |
| 言っていいこと | 以前との比較体験（感情込み）・素材・構造の違い |
| 言ってはいけないこと | 特定ブランドを「ゴミ」と断言（表現はOK、具体名はNG） |
| 感情の着地点 | 「もっと早く変えれば良かった」 |
| 推奨パターン | 比較体験談型 |
| 注意 | コメントが最も動くパターン。論争も生まれやすいため炎上リスクに注意 |

## 共通NG事項（全カテゴリー共通）

| NGワード・表現 | 理由 |
|---|---|
| 「安全性が証明されている」 | 医薬品的表現 |
| 「必ず〇〇できる」 | 効果の断言 |
| 「他社商品名＋ダメ」 | 競合他社への名指し批判 |
| 「医師推薦」「専門家推奨」 | 根拠なき権威付け |
| 「絶対漏れない」 | 使用状況による。「漏れにくい」はOK |

---

## 更新ルール

- コラボから新カテゴリーが追加されたら1週間以内にガイドライン追加
- リールマンの調査で新パターンが判明したらガイドラインに反映
- NGワードは法務・ブランド方針に基づき随時追加
