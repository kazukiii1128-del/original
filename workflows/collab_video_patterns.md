# コラボ｜インフルエンサー動画パターン集

## 役割

「コラボ」と呼ばれたら起動する。

GROSMIMIコラボインフルエンサー28投稿の分析をもとに、商品別・訴求軸別の動画構成パターンをまとめたもの。
今後の台本作成・インフルエンサーブリーフィングの参考資料として使用する。

**リールマンとの連携:** リールマンが競合調査した結果を受け取り、カテゴリー・アイデアに反映する。

**ガイドラインマンとの連携:** コラボが設計した構成パターンをガイドラインマンに渡し、カテゴリー別訴求ガイドライン（何を・どう伝えるかのルール）として整備させる。

## PPSUグループ（PPSUストローマグ・ワンタッチ式）

### カテゴリー① PPSU素材・安全性

**狙うパターン：逆張り教育型（いいね335参考）**
**参考インフルエンサー:** coni.ikuji / minkoro_kosodate / memeko_babyikuji

**冒頭フック**
> 「安いストローマグでいいや、ちょっと待って！」

**構成**
1. 「安いので十分」という先入観を提示
2. プラスチックに種類があることを知らない親が多い→教育
3. PPSUとは何か（BPAフリー・マイクロプラ非発生・耐熱）
4. 赤ちゃんが毎日使うものだからこそ → 感情に刺さる
5. 購入誘導

**キーワード**
`PPSU` `BPAフリー` `マイクロプラスチックなし` `赤ちゃんに安心` `毎日使うから素材が大事`

**強み:** 他社が言えない話をGROSMIMIが言える。差別化が最大になるカテゴリー

### カテゴリー② 漏れない

**狙うパターン：ペイン共感型（いいね428参考）**
**参考インフルエンサー:** rimaya_kosodate / maro.ikuzi / chii_mom_life

**冒頭フック**
> 「カバンの中でマグが漏れてたことある人〜？」

**構成**
1. 漏れた経験のあるあるで共感を取る
2. なぜ漏れるのか（ストロー構造の問題）
3. +CUTストローの仕組みを解説（逆止弁）
4. 実証動画（逆さ・振る・落とす）インパクト重視
5. 「外出中の不安がゼロになった」で締め

**キーワード**
`+CUTストロー` `逆さにしても漏れない` `振っても大丈夫` `外出安心` `カバンの中が安全`

**強み:** 実証動画のインパクトが強い。共感から入るので止まってもらいやすい

### カテゴリー③ 離乳食期に使える

**狙うパターン：ランキング・まとめ型**
**参考インフルエンサー:** memeko_babyikuji / minkoro_kosodate

**冒頭フック**

2. 6ヶ月〜対応・BPAフリーで安心して使えることを強調
3. 離乳食×マグをセットで「神グッズ」として紹介
4. 購入リンク誘導

**キーワード**
`離乳食デビューに` `6ヶ月から` `BPAフリー` `神グッズ` `離乳食と一緒に揃えて`

**強み:** #離乳食が超大型タグ。離乳食コンテンツに乗せることで新規層に届く

## ステンレスストローマグ

### カテゴリー① 医療グレードステンレス（保温保冷）

**狙うパターン：逆張り教育型（いいね335参考）**
**参考インフルエンサー:** mamapy_ikuji / shiro_ikuji

**冒頭フック**
> 「ステンレスマグなら全部同じだと思ってた」

**構成**
1. 「全部同じ」という先入観を提示
2. ステンレスに種類があることを教える（SUS201 vs 304 vs 316）
3. SUS316は医療器具にも使われるレベル → 信頼性
4. 保温6時間の実証シーン
5. 韓国発ブランドとしての権威性で締め

**キーワード**
`SUS316` `医療グレード` `保温6時間` `変色しない` `内側まで安全`

**強み:** 知識格差を使った差別化。他社が正面から言いにくい素材比較ができる

---

### カテゴリー② 漏れない（保温×漏れない両立）

**狙うパターン：ペイン共感型**
**参考インフルエンサー:** miimaru_baby0 / emachi_mom

**冒頭フック**
> 「ホットを入れて倒しても漏れないマグ、存在してた」

**構成**
1. 保温×漏れない両立の宣言
2. 保温実証（朝入れたお湯がまだ温かい）
3. 漏れない実証（逆さ・振る・落とす）
4. 外出・離乳食期のリアルシーンに重ねる
5. PPSUとの違いも軽く触れてステンレスを選ぶ理由へ

**キーワード**
`保温6時間` `HOT対応` `倒してもこぼれない` `外出に最強` `真空断熱`

**強み:** PPSUにはない「ホット対応」がステンレス固有の訴求になる

---

### カテゴリー③ つなぎ目なし（シームレス）

**狙うパターン：逆張り教育型＋論争型**
**参考インフルエンサー:** mayuka_mom

**冒頭フック**
> 「ステンレスマグ、内側に継ぎ目があるやつ使ってない？」

**構成**
1. 継ぎ目がある＝汚れ・カビのリスクを提示（ペイン）
2. 溶接vs シームレスの構造比較を見せる
3. GROSMIMIのシームレス構造で解消できると解説
4. 衛生面の安心感で締め

**キーワード**
`シームレス構造` `継ぎ目なし` `カビない` `匂いがつかない` `内側まで清潔`

**強み:** 「カビ」「汚れが取れない」ペインに直撃できる

---

### カテゴリー④ 比較・買い替え訴求

**狙うパターン：比較体験談型（コメント32件参考）**
**参考インフルエンサー:** mayuka_mom / coni.ikuji

**冒頭フック**
> 「今まで使ってたマグ、正直ゴミだったと気づいた話」

**構成**
1. 他社マグを使っていたビフォーを提示
2. 素材・構造の比較（溶接 vs シームレス / 201 vs 316）
3. 使ってみてわかった差を感情込みで話す
4. 「第二子はこれ一択」「もっと早く変えれば良かった」で締め

**キーワード**
`他社との違い` `後悔した` `これに変えて正解` `第二子はこれ一択` `買い替えて正解`

**強み:** 比較＋感情系はコメントが一番動く。論争も生まれやすい

### 反復視聴コンテンツ型（5型）

| 型 | なぜ反復視聴されるか |
|---|---|
| ループ動画 | 終わりが始まりに繋がる構造 |
| スロー実証 | 目が追う、一回では確認しきれない |
| 伏線回収 | 最初の「え？」が最後に回収される |
| テロップ情報密度 | 一回じゃ全部読めない |
